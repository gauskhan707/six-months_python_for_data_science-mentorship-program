Project 1: Smart Calculator & Unit Lab

▾

Brief. A REPL calculator that evaluates arithmetic safely (no eval on raw input — parse it!), tracks history, and converts units (temperature, length, data-size). Why: proves Chapters 1–10 fluency (I/O, types, operators, strings, lists, dicts, branching, loops) in one shippable tool with real parsing and real edge cases.

Requirements. ① REPL loop (quit/history/clear commands; Ctrl-C exits cleanly). ② Safe evaluator: tokenize → parse → compute supporting + - * / // % **, parentheses, unary minus, floats (recursive-descent or shunting-yard — YOUR parser, not eval!). ③ Unit lab: 100C to F, 5km to m, 2048MB to GB (normalize units, validate domains — no −300°C!). ④ History: last N with recall (!3 re-runs entry 3). ⑤ Errors that TEACH (3 + → "expected a number after '+'" with position carets, not tracebacks).

Milestones. M1: REPL + + - * / (no parens) + history list. M2: precedence + parens + unary + // % **. M3: unit conversions + validations. M4: !n recall + error carets + help text. M5: polish (docstrings, hints, README, 15+ asserts-as-tests in a test_calc.py).

Acceptance. 2 + 3 * 4 → 14 · (2+3)*4 → 20 · 2**3**2 → 512 (right-assoc!) · 7/0 → friendly error · 100C to F → 212 · -40C to F → −40 (the crossover!) · garbage → caret error, REPL survives · !2 replays · 15 tests green.

Stretch. Variables (x = 5) · functions (sqrt(16)) · --expr "2+2" CLI mode · timing per eval (§21.1).

Project 2: Text Analyzer Studio

▾

Brief. A CLI that profiles any text file: counts, top words (stopword-aware), reading level, n-grams, concordance (keyword-in-context), and a comparison mode (two files' vocab overlap). Why: strings + collections + files + comprehensions at realistic scale — the exact wrangling core of NLP (Part 6 preview, stdlib-only!).

Requirements. ① analyze book.txt: chars/words/sentences/paragraphs, unique words, type-token ratio, avg word/sentence length. ② Top-N words with stopword filtering (ship a stopwords.txt`; flag: --no-stop). ③ Bigrams/trigrams top-N (zip + Counter). ④ concordance word --width 40: every occurrence with context (generators — don't load 100MB!). ⑤ compare a.txt b.txt: shared vocab %, distinctive words per file (Counter subtraction!). ⑥ Encodings: --encoding flag + errors policy (§15.6); BOM-safe (§15.6's utf-8-sig!).

Milestones. M1: counts + top words on one file. M2: stopwords + n-grams. M3: concordance (streaming). M4: compare mode. M5: encoding flags + tests + README with sample outputs.

Acceptance. Self-analyzes its own README correctly (hand-verify top-5!) · 50MB file processes in O(1) memory (prove: tracemalloc peak!) · BOM file reads clean · comparison %s sum sanely · all flags documented in --help.

Stretch. Reading-ease score (Flesch) · hapax legomena (words used once) · JSON report output · --top configurable everywhere.

Why: the full application shape — pure-core logic + I/O shell, validation, persistence, CLI config, venv+requirements, tests — a portfolio piece proving job-ready craft.

Milestones. M1: add+list over CSV (manual testing). M2: report math (pure functions + tests!). M3: budgets + warnings. M4: atomic writes + export/import round-trip. M5: venv + requirements + pytest suite (≥20 tests) + README (setup/usage/examples).

Acceptance. Fresh clone → README's 3 commands → working app · invalid inputs rejected with guidance (never tracebacks) · mid-write kill loses ≤ the in-flight row (prove!) · 20 tests incl. error paths + round-trip · ruff + mypy clean.

Stretch. Receipt-note search · --currency config · recurring expenses · lru_cache on monthly aggregates (with invalidation on add!).

Project 4: Robust Data Pipeline

▾

Brief. A production-shaped ETL: stream a messy 100k-row CSV → validate + clean (pure stages) → quarantine rejects with reasons → load clean rows to JSONL + summary report, with retries, timing, logging, and idempotent re-runs. Why: THE data-engineering miniature — every pattern (generators, exceptions, CMs, decorators, logging, atomic writes, ExitStack) composed under dirty-data fire. Interview gold.

Requirements. ① Generator pipeline (§19.5): read → parse → validate → normalize → write — O(1) memory at 100k rows (prove via tracemalloc!). ② Row contract: typed schema (dataclass!), per-field validators, RowError(row_no, field, reason, raw) — rejects to quarantine.csv WITH reasons (never silent!). ③ Resilience: @retry on the (simulated-flaky) source reader + @timer per stage + counts logged per 10k rows. ④ Outputs: clean.jsonl + report.txt (rows in/out/rejected, per-reason counts, per-stage timings, seed) + run.log — ALL atomic (§15.8). ⑤ Idempotent: re-run overwrites deterministically (same input+seed → byte-identical outputs — assert in tests!). ⑥ --dry-run (validate only, no writes) + --limit N + --seed flags.

Milestones. M1: streaming read→write skeleton + row counting. M2: schema + validators + quarantine. M3: retries/timers/logging + report. M4: atomic outputs + idempotence proof + flags. M5: dirty-data torture suite (10 corruption types!) + README + architecture note.

Acceptance. 100k messy rows → correct clean/quarantine split (hand-verify 20 rejects' reasons!) · O(1) memory (peak logged!) · kill mid-run → no partial outputs · re-run → byte-identical · torture suite (bad encodings! ragged rows! null bytes! dup headers!) all handled-or-quarantined, zero crashes.

Stretch. --workers (ProcessPool chunk fan-out — §24.5!) · schema-as-TOML config · sqlite3 load target · progress bar (hand-rolled, no deps!).

Project 5: Mini-ML Toolkit (from scratch!)

▾

Brief. Machine learning with zero ML libraries (stdlib only!): a Dataset class (load/profile/clean/split), k-NN + majority-baseline classifiers with sklearn-shaped fit/predict/score, metrics (accuracy/confusion-matrix), and a seeded experiment runner comparing models. Why: proves the book's thesis — Part-1 Python alone builds real ML tooling (and you'll understand sklearn forever, because you've been sklearn).

Requirements. ① Dataset (dataclass rows!): from_csv (streaming + quarantine, reuse P4's patterns!), profile(), train_test_split(test_size, seed) (seeded shuffle §25.4; assert disjoint + exhaustive!). ② MajorityClassifier (fit=majority label; the baseline every model must beat!) + KNNClassifier(k) (fit=memorize; predict=k-nearest vote, ties→smallest label, document!). ③ Metrics: accuracy, confusion_matrix (nested dict!), per-class precision/recall (pure functions + tests with hand-computed tables!). ④ experiment.py: seeds × k-values grid → results table (stdout + results.csv) → winner + margin-over-baseline verdict. ⑤ OOP discipline:estimators share a base class (documented contract!), dunders where earned (__len__/__repr__), properties for fitted-state guards (predict-before-fit → clear error!).

Milestones. M1: Dataset load+split (+ split-invariant tests!). M2: Majority + accuracy (first experiment runs!). M3: k-NN + confusion matrix (hand-verified!). M4: experiment grid + precision/recall. M5: polish (hints/mypy, 25+ tests, README with results table + "what I'd try in Part 5" section).

Acceptance. Bundled 300-row dataset (generate it deterministically!) → full grid runs in seconds · k-NN beats baseline by a logged margin · hand-verified confusion matrix on a 12-row fixture · split invariants hold across 10 seeds · predict-before-fit errors clearly · README's table reproducible via one command.

Stretch. Min-max scaler (fit-on-train-ONLY discipline!) · stratified split · cross-validation · timing/memory report per k (Ch. 24!).
