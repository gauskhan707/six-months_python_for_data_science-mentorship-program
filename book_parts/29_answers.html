A.1 Chapters 1–5 (setup → operators)

Ch1 L1: install proof + REPL vs script + versions
python --version → 3.10+ (3.8 EOL'd — upgrade!). REPL: instant feedback, exploratory, stateful-but-throwaway (§2.6); scripts: saved, rerunnable, shareable, testable. Versions differ in syntax available (match 3.10, X|None 3.10, tomllib 3.11, venv default 3.3+) — always know yours (sys.version).
Ch2 L2: comment-out debugging + help() discovery
Bisect-by-comment: halve the file, run, keep the failing half (~log₂(n) steps — §22.2's origin!). help(print) reveals sep/end/file/flush — the file/flush pair previews Ch. 15/23 (redirect + unbuffered logs).
Ch3 L1/L2: aliasing, == vs is, default-arg trap
L1: a = b = [] → ONE list, two names; a.append(1) shows in b (aliasing!). == compares values ([1]==[1] True, different objects!); is compares identity (True only same object). L2: default-arg trap — def f(x=[]) shares ONE list across calls (defaults evaluate once!); fix: def f(x=None): x = x or []. [[]]*3: three refs to ONE inner list; fix: [[] for _ in range(3)].
Ch4 L1/L2: float equality, True==1, conversion table
0.1+0.2 == 0.3 → False (0.30000000000000004 — binary fractions!); fix: math.isclose / pytest.approx / Decimal-for-money. True == 1 → True (bool subclasses int! — True+True == 2). Conversions: int("3")✓ int("3.5")✗ int(3.9)→3 (truncate-toward-zero, NOT floor for negatives: int(-3.9)→-3!).
Ch5 L1/L2: precedence, and/or values, banker bugs
Precedence: 2+3*4**2 = 2+3*16 = 50 (** first, right-assoc: 2**3**2=512!). and/or return OPERANDS (0 or [] or "x" → "x"; "a" and 0 and "b" → 0) — not booleans! Chained a<b<c = a<b and b<c with single evaluation (use for ranges!). not binds loosest of the three: not a == b = not (a==b).

A.2 Chapters 6–10 (strings → loops)

Ch6 L1/L2: email pipeline, f-string mastery, split traps
Pipeline " Ali.Raza@Mail.Com " → strip → lower → split("@") → "ali.raza@mail.com" (§6 verified output!). f-specs: f"{x:.2f}" (2dp), f"{n:,}" (thousands), f"{p:.1%}" (percent), f"{v=!r}" (debug). split() (any-whitespace, strips empties) vs split(" ") (exact-space, keeps empties — "a b".split(" ") → ['a','','b']!). Emails: validate with parts-count + no-spaces (regex in later parts).
Ch7 L1/L2: methods, aliasing, top-N
In-place (sort/reverse/append/extend → None!) vs new (sorted/reversed/slice/concat). nums=[5,7,9] → even-search prints "no even number" (verified §10 loop!). Top-N: sorted(scores, reverse=True)[:3] (or heapq.nlargest). Slice assignment a[1:3] = [x] resizes (length can change!).
Ch8 L1/L2: tuple swap, Counter bands, set ops
Swap: a, b = b, a (RHS tuple built first — atomic!). Unpacking: first, *rest = xs; _ for throwaways. Counter: Counter(ages) + most_common(3); banding via dict-comp over thresholds. Sets: a | b (union), a & b (intersection), a - b (difference), a ^ b (symmetric) — dedupe + membership at O(1).
Ch9 L1/L2: guards, banding, truthiness
Guard order: cheapest/most-discriminating first; validate-then-compute. Grade banding: if score >= 90: "A" elif >= 80… (boundaries tested at 89.999/90!). Ternary for VALUES ("pass" if s>=40 else "fail"), never for actions. Truthiness: empty/None/0/False → False; non-empty/nonzero → True — if items: over len>0.
Ch10 L1/L2: enumerate/zip, break/else, search pattern
enumerate(xs, start=1) for numbered; zip stops at shortest (document or zip_longest!). for/else: else runs iff NO break (search-miss handling — the nums=[5,7,9] "no even" demo!). while: condition + progress-guarantee (else infinite — always identify the shrink!). Replacement ladder: loop → comprehension → builtin → (later) vectorize.

A.3 Chapters 11–15 (functions → files)

Ch11 L1/L2: signatures, closures, decorators-preview
Arg order: positional → *args → keyword-only → **kwargs; defaults immutable-or-None. Closure: inner fn + captured cell (__closure__ proof); nonlocal to rebind (counter!). Recursion: base + shrink + trust (trace factorial(3): 3*2*1). Decorator = f = d(f) + wrapper + wraps (full Ch. 21!).
Ch12 L1/L2: LEGB traces, global/nonlocal, loop-var leakage
LEGB: Local → Enclosing → Global → Builtin (first hit wins). Assignment binds LOCAL (read-then-assign → UnboundLocalError!). global: rebind module var (avoid — return/params instead). Loop/comprehension vars leak in for (i survives!) but NOT genexps (own scope). Fix shadowing: rename, never reuse builtins (list, id, sum!).
Ch13 L1/L2: filter-vs-ternary, boundary trace, nesting
Filter [x for x in xs if p] EXCLUDES; ternary [a if p else b for x in xs] TRANSFORMS (same length!). Boundary: [x*x if x>2 else -x for x in range(6) if x!=0] = [-1,-2,9,16,25] (filter drops 0 FIRST, then ternary maps — verified!). Nesting: at most 2 levels inline; name complex predicates. Genexps: sum(… for …) — O(1).
Ch14 L1/L2: hierarchy, else/finally, quarantine
Order excepts specific→broad (ValueError before Exception!). else = try-succeeded path; finally = always (cleanup!). raise New from old preserves cause (traceback shows BOTH). Quarantine: per-row try/except → (good, rejects-with-reason) — counts + reasons, never silent. Custom: subclass Exception (never BaseException!), one per failure mode.
Ch15 L1/L2: with-guarantee, encodings, atomic writes
with open: close+flush guaranteed across exceptions/returns (vs leak-prone bare open!). Encoding: ALWAYS encoding="utf-8" (or utf-8-sig for BOM!); errors="replace" for hostile data (logged!). Newline: newline="" for csv (no phantom blanks!). Atomic: write-temp + os.replace (readers see old-or-new, never half!). JSON: json.dump + UTF-8 + round-trip test.

A.4 Chapters 16–20 (modules → functional)

Ch16 L1/L2: imports, __main__ guard, circular
Guard: if __name__ == "__main__": main() (import-safe!). Absolute imports preferred; sys.path[0] = script dir (run as python -m pkg.mod from root!). Circular: A↔B top-level imports → ImportError/partial-module — fix by extracting shared module or deferring import. __all__ declares public API.
Ch17 L1/L2: venv proof, freeze discipline, triage
Proof: which python → .venv/… + pip list minimal. Freeze: pip freeze > requirements.txt AFTER verifying (pins transitive too!); recreate: venv → install → run tests. Triage: wrong-exe (which!) → not-installed-here (pip show) → drift (diff freeze) → cache/corrupt (recreate). Never sudo-pip / never system-python projects.
Ch18 L1/L2: self, properties, dataclasses, dunders
self: instance the method was called on (binding, not keyword!). Property: computed/validated attribute access (@prop.setter validates!). Dataclass: @dataclass → init/repr/eq free; field(default_factory=list) for mutables; frozen=True for hashable values. Dunders: __len__/__getitem__/__eq__/__repr__ = protocols (implement → builtins work!). super(): cooperative MRO chain (call it!).
Ch19 L1/L2: iterator protocol, yield-freeze, pipelines
Protocol: __iter__ + __next__ + StopIteration (for-loop drives it!). yield freezes frame (locals preserved; resumes after!). Single-use: generators exhaust (re-call factory for fresh!). Pipeline: read→parse→filter→aggregate, O(1) (prove: getsizeof + tracemalloc!). yield from delegates (+ returns subgenerator's return!). Infinite: count/repeat/cycle + islice to take.
Ch20 L1/L2: twins rule, any/all, groupby, lru_cache
Twins: named-fn → map/filter OK; lambda → comprehension wins; reduction → builtin first (sum/any/prod). any stops at first-True; all([]) True (vacuous!). groupby groups CONSECUTIVE (sort first or defaultdict!). lru_cache: pure + hashable + bounded (fib(100) instant; cache_info proves!). operator.itemgetter beats lambdas for keys.

A.5 Chapters 21–25 (patterns → bridge)

Ch21 L1/L2: decorator mechanics, factories, CMs
@timer def f ≡ f = timer(f) at def-time; wrapper: *a/**k + return fn(*a,**k) + wraps (all three, always!). Factory: config→decorator→wrapper (retry demo). Stacking: bottom-first-applied, top-first-run (order is behavior — argue from call path!). CM: enter→body→exit-always (args = outcome!); gen-CM = one yield in try/finally; truthy exit suppresses (rare!). ExitStack for dynamic N.
Ch22 L1/L2: workflow, tracebacks, pdb, cause-fixes
Loop: understand → bottom-up (last line FIRST!) → locate → repro-minimal (bisect!) → inspect → one-hypothesis → cause-fix → regression-test. Crash site ≠ fault site (fix the ORIGIN!). pdb: breakpoint() + n/s/c/p/w/u/b (+ post-mortem -m pdb). Symptom-fix (try around crash → silent corruption!) vs cause-fix (contract at fault + validation upstream). Every fix ships a test.
Ch23 L1/L2: style, naming, logging, config, tests
Ruff: check + format (on-save + CI). Names: full words, units (timeout_s!), predicates (is_valid), verb-fns, plural-collections. Logging: levels/names/lazy-%s/exception() (never print in libs!). Config: args>env>file; secrets in ENV, never git. pytest: parametrize, approx floats, tmp_path files, error-paths, purity asserts. README: 3-commands-to-green + checklist sign-off.
Ch24 L1/L2: measure-first, Big-O crimes, GIL, memory
Instruments: timeit (snippets), perf_counter (stages), cProfile (hotspots — top cumulative row!). Crimes: in list→set, insert(0)→deque, +=→join, re-sort→bisect, nested-same-data→index-first. GIL: threads=I/O, processes=CPU, async=fan-out, NumPy=releases-GIL. Memory: stream (O(1)), materialize-to-reuse, tracemalloc diffs leaks, slots for millions. Stop at budget!
Ch25 L1/L2: why-Python, workflow, seeding/splits
Five reasons: readable glue, C-libs, notebooks, ecosystem, general-purpose (+honest limits!). Workflow: ask→get→clean→explore→model→communicate→deploy (Part-1 core each stage!). Pipeline: pure clean + reject-reasons + set-dedupe + Counter-profile + seeded shuffle-split (seed LOGGED!). Series: SQL/stats → NumPy/pandas → viz → ML → DL/NLP/LLMs (each assumes THIS book!).

Mastery Checkpoint

▾

What/why. Reading ≠ knowing. This checkpoint certifies Part-1 mastery through three gates: a knowledge exam (answer cold), a practical exam (build cold), and the capstone (ship something real). Pass all three and you don't just "know Python" — you operate in it: read, write, debug, test, and explain at a professional level. Rules: closed-book for Gate 1 (docs allowed for Gates 2–3 — professionals read docs!); no AI code-writing (AI questions OK — "why does X behave Y?" teaches; "write X" doesn't); log your hours (mastery is measured in reps!).

C.1 Gate 1: knowledge exam (cold, 90 minutes)

Answer all 15 canon questions (§I.1) aloud, with whiteboard demos, plus: trace [x*x if x>2 else -x for x in range(6) if x!=0] exactly (→ [-1,-2,9,16,25]); expand @retry(n=3) to its three levels; read a 3-frame traceback bottom-up (mark crash vs fault sites); state Big-O + fix for 3 planted crimes (membership/dedupe/concat). Pass: 13/15 fluent (demos run!), trace exact, traceback correct, 3/3 crimes fixed. Remediation: miss → re-read that chapter → re-take in 3 days.

C.2 Gate 2: practical exam (cold, 3 hours, docs allowed)

Build checkpoint_lab.py from a blank file: streaming CSV profiler (counts, Counter top-N, missing-%, reject-quarantine with reasons) + --top/--encoding/--limit flags + atomic report.txt + seeded sample-split + 10 pytest tests + ruff-clean + timed stages logged. Pass: runs on a messy 10k-row fixture (provided-by-you, 5+ corruption types!) with correct outputs, O(1) memory (tracemalloc evidence!), all tests green, zero tracebacks on hostile rows. This is P2+P4 compressed — your floor, not your ceiling.

C.3 Gate 3: capstone (1–2 weeks, portfolio-grade)

Ship one: (a) a novel project combining ≥3 project-patterns (e.g., log-studio: P2-text + P4-pipeline + P5-baseline-classifier on log severities!); or (b) a deep extension of P4/P5 (workers + config-file + SQLite target + full torture suite). Must include: venv + frozen requirements · pytest suite (≥25 tests, error-paths + invariants + regression-per-bug-found!) · logging + argparse config · atomic outputs · README (setup/usage/architecture/decisions/results) · ruff + mypy clean · GitHub repo with meaningful commit history (≥10 commits showing iteration!). Pass: a peer (or mentor/AI-reviewer) clones → 3 commands → green tests + correct outputs + can explain your architecture from the README alone.
